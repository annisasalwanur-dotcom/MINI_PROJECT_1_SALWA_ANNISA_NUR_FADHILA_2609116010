# MINI_PROJECT_1_SALWA_ANNISA_NUR_FADHILA_2609116010
Mulai : Menyiapkan wadah kosong untuk menampung data karyawan.
Menu Utama: Tampilan berulang tempat kamu memilih angka 1 sampai 5.
​Pilihan 1 (Tambah): Kamu memasukkan nama dan golongan. Sistem mengecek golongannya. Jika valid (A-E), kamu diminta isi gaji lalu data disimpan.
​Pilihan 2 (Tampilkan): Sistem mengecek apakah ada data. Jika kosong, muncul pesan "Belum ada data". Jika ada, semua nama dan gaji ditampilkan satu per satu.
​Pilihan 3 (Ubah): Kamu ketik nama karyawan. Sistem mencari data tersebut:
​- Ketemu: Masukkan data baru untuk memperbarui data lama.
​- Tidak Ketemu: Muncul pesan "Data tidak ditemukan".
​Pilihan 4 (Hapus): Kamu ketik nama karyawan. Jika ketemu, data orang tersebut langsung dibuang dari daftar.
​Pilihan 5 (Keluar): Program berhenti berjalan.
